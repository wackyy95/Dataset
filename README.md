# Dataset
The dataset for the mobile application 
the dataset is comprised of a number of different images both taken by users of the application aswell as taken from a variety of different datasets.
the dataset is comprised into 5 classes:
1. healthy
2. melanoma 
3. chicken pox
4. monkey poc
5. atopic dermatitis


ISIC 2020
challenge.isic-archive.com. (n.d.). ISIC Challenge.  Available at: https://challenge.isic-archive.com/data/.
dermnetnz.org. (n.d.). Atopic Dermatitis Images — DermNet.  Available at: https://dermnetnz.org/images/atopic-dermatitis-image

SCIN Dataset
google-research-datasets (2024). GitHub - google-research-datasets/scin: The SCIN dataset contains 10,000+ images of dermatology conditions, crowdsourced with informed consent from US internet users. Contributions include self-reported demographic and symptom information and dermatologist labels. The dataset also contains estimated Fitzpatrick skin type and Monk Skin Tone. [online] GitHub. Available at: https://github.com/google-research-datasets/scin
